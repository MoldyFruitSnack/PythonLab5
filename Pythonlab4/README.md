Encapsulation helped break down the drawing process because we were able to 
turn a multistep process of creating a pumpkin with a stem, eyes, and mouth,
into a simplified way of calling the function.
    Generalization helped with this a great deal too as we needed multiple jackolanterns 
in varying positions and sizes, and it allowed us to add a parameter to do this. 
    Without encapsulation and generalization the code would have been a lot 
messier and  more confusing than it needed to be.
